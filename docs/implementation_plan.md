# 首期实现计划

范围：已裁剪、完整物理源的分类；不实现检测、关联或AION，不声称真实科学性能。

1. 编写数据科学约束测试：负值/NaN、立方体拒绝、跨分区组泄漏、缺失类别指标。
2. 实现 data.py：CSV清单校验、二维FITS读取、双通道强度/有效掩码，固定尺寸拒绝隐式缩放。
3. 实现 model.py 与 engine.py：小型CNN、交叉熵训练、验证选优、独立测试、模型加载预测。
4. 实现 demo.py：仅用于工程测试的高斯形态模拟数据。
5. 执行测试和端到端训练、评估、预测；提供逐段中文讲解和下载包。

接口：Dataset返回(image[2,H,W], label, sample_id)；CNN返回未归一化logits。
数据约束：group_id由用户预先根据天空区域及重叠关系定义，脚本仅检查组不跨分区，不能替代空间审计。
